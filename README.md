# WIRDAN — مشروع اختبار الجدوى (مؤقت)

هذا مشروع تجريبي صغير يتحقق من أن مكتبات Windows (الإشعارات، الصوت، System Tray،
قاعدة البيانات، التشغيل التلقائي، نسخة واحدة) والمثبّت تعمل فعلاً على جهازك.
بعد نجاحه يُحذف ونبدأ مشروع WIRDAN الحقيقي.

## كيف يُبنى
عند رفع الملفات إلى فرع `main` يعمل GitHub Actions تلقائياً ويبني `WIRDAN-Spike-Setup.exe`.
لا تحتاج أي أدوات تطوير على جهازك.

## المثبّت
- تثبيت لكل مستخدم (بدون Administrator).
- يضمّ مكتبات VC++ داخله.
- غير موقّع رقمياً: سيُظهر Windows تحذير SmartScreen.
